## 도메인 옮기기

1. 도메인을 사고, DNS 에 **A 레코드 → 34.44.40.196** 을 넣는다.
2. 서버에서 `cd /srv/hanjang && sudo sh deploy/setup.sh <새 도메인>` — 다시 돌려도 괜찮은 스크립트다. `.env` 의 `BASE_URL` 과 Caddy 주소를 새 도메인으로 바꾸고, https 인증서는 Caddy 가 저절로 받는다.
3. 옛 주소로 들어오는 사람을 넘겨주려면 `/etc/caddy/sites/old.caddy` 에 한 줄 넣고 `sudo systemctl reload caddy`:
   `34-44-40-196.sslip.io { redir https://<새 도메인>{uri} permanent }`
4. 쿠키는 주소마다 따로라 **모두 한 번씩 다시 로그인**한다(메일 링크).

## 플레이스토어 (TWA — 웹을 그대로 감싼 안드로이드 앱)

- 만드는 법: [PWABuilder](https://www.pwabuilder.com) 에 새 도메인을 넣고 Android 꾸러미를 받는다(안에서 구글 Bubblewrap 이 돈다). 웹을 고치면 앱도 바로 바뀐다.
- 꾸러미의 **서명 키 SHA-256 지문**과 패키지 이름을 `.env` 의 `TWA_SHA256`·`TWA_PACKAGE` 에 넣으면 `/.well-known/assetlinks.json` 이 열린다. 이게 있어야 앱 위쪽에 주소창이 안 보인다.
- **개인 개발자 계정**(2023-11-13 이후 만든 것)은 **테스터 12명이 14일 동안 계속 참여한 비공개 테스트**를 거쳐야 정식 출시를 신청할 수 있다. 사업자(조직) 계정은 면제 ([구글 안내](https://support.google.com/googleplay/android-developer/answer/14151465)). 20명 시험 참여자 중 안드로이드 사용자를 테스터로 넣으면 시험과 함께 채워진다.
- 플레이 콘솔 「금융 기능 신고」 — 한장은 매매·송금이 없으니 **금융 기능 없음** ([구글 안내](https://support.google.com/googleplay/android-developer/answer/13849271)).
- 데이터 보안 양식: 받는 것은 이메일 하나, 광고·추적 없음, 탈퇴하면 바로 삭제 — [policy.py](../hanjang/policy.py) 처리방침과 같게 적는다.

## 앱스토어 (나중)

- **4.2 최소 기능**: 웹을 감싸기만 한 앱은 자주 거절된다. 비행기 모드에서 흰 화면이 뜨면 바로 걸린다 → 오프라인 화면은 넣어 두었다. 푸시 알림·위젯처럼 앱에서만 되는 기능이 더 필요할 수 있다.
- **5.1.1(v) 계정 삭제**: 앱 안에서 바로 탈퇴 — 이미 된다 ([애플 안내](https://developer.apple.com/support/offering-account-deletion-in-your-app)).
- 카카오 로그인을 붙이면 애플 로그인(또는 같은 수준의 개인정보 보호 로그인)도 요구될 수 있다(4.8).

## Lighthouse (10/10, 로그인 화면 · 느린 4G 가정)

실제 서버(https://34-44-40-196.sslip.io, 미국 서버를 한국에서 잼) 기준. 내 컴퓨터의 개발 서버는 압축·HTTP/2 가 없어 훨씬 낮게 나오니 실제 서버로 잰다.

| 속도 | 80~84 (첫 화면 3.4초) | **88~94** (2.5초) |
