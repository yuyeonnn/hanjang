# 플레이스토어에 넣을 것 (2026-10-12)

플레이 콘솔에서 그대로 붙여 넣는다. 화면에 없는 것·하지 않는 것은 적지 않는다(심사는 설명과 앱이 다르면 거절한다).

## 앱 파일

- 꾸러미 이름: `com.hanjangapp` (한 번 올리면 못 바꾼다)
- 만드는 곳: `C:\hanjang-android\` (저장소 밖) — `app/` 프로젝트 · `keys/` 올리기용 서명 열쇠와 비밀번호 · `jdk/` `sdk/` 도구
- 다시 만들기(아이콘·이름을 바꿨을 때만 — 화면·기능은 서버에 올리면 바로 바뀐다):
  `app/twa-manifest.json` 의 `appVersionCode` 를 1 올리고, `tool/gen.js` → `bubblewrap build --skipPwaValidation`
- **서명 열쇠(`keys/`)는 따로 한 부 보관한다.** 잃어도 플레이 콘솔에서 올리기 열쇠를 다시 등록할 수 있지만(플레이 앱 서명), 며칠 걸린다.
- 앱과 사이트 잇기: 플레이 콘솔 「앱 무결성 → 앱 서명」의 **앱 서명 키 SHA-256** 과 올리기 열쇠 SHA-256 을 서버 `.env` 의 `TWA_SHA256` 에 쉼표로 둘 다, `TWA_PACKAGE=com.hanjangapp`. 그러면 `https://hanjangapp.com/.well-known/assetlinks.json` 이 열리고 앱에서 주소창이 사라진다.

```
한장은 내가 가진 주식에 지금 무슨 일이 있는지, 흩어진 공시·재무·소식을 엮어 쉬운 글 한 장으로 보여 줍니다.

■ 내 종목 노트
종목을 담으면 그 회사를 설명하는 글 한 장을 볼 수 있어요. 어떤 사업으로 돈을 버는지, 최근 실적이 어땠는지, 요즘 어떤 공시가 나왔는지를 쉬운 말로 이어서 적습니다.

■ 피드

■ 캘린더
내 종목의 실적 발표, 배당, 주주총회 일정과 공모주 청약 일정을 한눈에 봅니다.

■ 큰손
국민연금과 유명 투자자가 가진 종목, 지분이 늘고 준 내용을 공시 기준으로 보여 줍니다.

배당, 유상증자, 부채비율 같은 말을 쉽게 풀어 주는 글과 짧은 퀴즈가 있어요.

· 「사라, 팔아라」를 말하지 않습니다. 매수·매도 의견, 목표 주가, 주가 예측은 싣지 않습니다.

· 수익을 약속하지 않습니다. 한장이 약속하는 것은 이해입니다.

■ 알아 두세요
· 한장은 투자 자문이 아니라 공시 정보를 쉽게 풀어 주는 서비스입니다. 투자 판단과 책임은 본인에게 있습니다.
· 글은 금융감독원 전자공시(DART)와 회사가 공개한 자료를 바탕으로 AI가 쓰고, 숫자는 코드가 원문과 대조합니다.
· 주가 시세는 제공하지 않습니다.
· 이메일만으로 시작해요. 비밀번호가 없습니다.
```

서버 `.env` 에 `REVIEW_EMAIL`·`REVIEW_CODE`(숫자 6자리)를 넣은 뒤:
```
1. 이메일 칸에 <REVIEW_EMAIL> 입력, 동의 체크, 「시작하기」

3. 닉네임을 정하고 이용 규칙에 동의하면 모든 화면을 쓸 수 있습니다
```
