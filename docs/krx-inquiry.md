> 받는 곳: **한국거래소 KRX Data Marketplace** (data.krx.co.kr 의 데이터 상품·이용 문의 창구).
> 같은 문안으로 **코스콤**, **에프앤가이드**에도 보내 값과 조건을 비교한다 ([data-rights.md](data-rights.md) §4).

**제목**: [견적 문의] 개인 개발 모바일 웹의 주식 종가 표시용 데이터 이용 조건

안녕하세요. 개인이 만들고 있는 모바일 웹 서비스 「한장」의 시세 데이터 이용 조건과 비용을 여쭙고 싶습니다.

**서비스 소개**
- 사용자가 고른 국내 주식에 대해 공시·재무를 쉬운 글로 풀어 주는 서비스입니다. 매수·매도 권유나 주가 예측은 하지 않습니다.
- 지금은 지인 20명 정도가 6주 동안 써 보는 시험 단계이며, 무료입니다. 시험 결과에 따라 유료화를 검토합니다.

**원하는 데이터와 쓰는 방법**
1. 코스피 시가총액 상위 약 100종목의 **일별 종가와 시가총액**. 실시간이 아니라 **하루 늦은 값**이면 충분합니다.
2. 종목마다 **최근 1년 종가 흐름을 작은 선 그림**으로 웹 화면에 보여 주고, 수익률·PER·PBR 같은 가공 숫자를 계산해 글에 씁니다.
3. 원자료를 내려받게 하거나 다른 곳에 다시 파는 일은 없습니다.
4. (가능하면) **코스피 지수** 일별 값도 같은 방식으로 쓰고 싶습니다.

**여쭙고 싶은 것**
1. 위 용도에 맞는 상품과 월(또는 연) 비용
2. 무료 시험 단계(이용자 20명 안팎)와 유료화 이후의 조건 차이
3. 화면에 표시할 때 꼭 지켜야 할 출처 표시 문구
4. OECD 가 공개한 한국 주가지수(월평균, 2015=100)를 교육용 글의 차트에 쓰는 것도 거래소의 허락이 필요한지

회신 주시면 감사하겠습니다.
