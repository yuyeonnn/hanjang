# 한장 — 앱 구상

> **결정이 아니라 구상 기록이다.** 2026-10-07 퀀트점프(`quant-jump`) 대화에서 정리해 이 프로젝트로 옮겼다.
> 재료는 퀀트점프 엔진에서 오지만, 퀀트점프는 **나 혼자 쓰는 엔진**으로 남는다. 한장은 퀀트점프가 내보내는 **공개용 파일만** 읽는다 (§7).
> 법·데이터 사용권·경쟁에 관한 내용은 전부 **확인 전 가정**이다 (§8).

---

## 1. 이름

**한장 (Hanjang)** — 내 종목을 **한 장**으로 정리한다. 기업 노트 한 장이라는 제품 모양이 이름에 그대로 있다.
출시 전에 **상표(KIPRIS)·앱스토어·도메인 중복**을 확인한다.

---

## 2. 한 줄 정의

**내가 가진 주식이 지금 어떤 상황인지, 공시·재무·뉴스·수급을 쉬운 글 한 장으로 꿰어 보여주는 앱.**

- 네이버·토스는 정보를 **늘어놓는다** — 지표·표·요약이 많지만 초보자는 꿰어 읽지 못한다.
- 한장은 정보를 **설명한다** — 「무슨 일이 있었고, 그게 무슨 뜻이고, 회사 사정은 어떤가」.
- 약속하는 것은 **수익이 아니라 이해**다. 「사라/팔아라」·비중·예측은 넣지 않는다.

---

## 3. 누구를 위한 앱인가

| | |
|---|---|
| **사용자** | 토스·네이버로 주식을 사긴 했는데, 그 회사가 지금 어떤지는 잘 모르는 사람 |
| **불편** | 공시·재무제표·리서치는 용어가 낯설다. 앱마다 숫자는 많은데 「그래서 괜찮은 건가」를 알려주지 않는다 |
| **원하는 것** | 내 종목에 관한 것이 **한 곳에, 읽히는 말로** 있는 것 |

---

## 4. 화면 4개

| 화면 | 내용 | 엔진에서 가져오는 것 |
|---|---|---|
| **① 오늘의 경제 뉴스** | 큰 경제 뉴스를 뉴스레터처럼 쉽게 풀어서. **「이 뉴스가 내 종목에 닿는 길」**을 함께 (§5) | 거시 지표·종목별 거시 민감도 |
| **② 내 종목 카드** | 보유·관심 종목을 넣으면 종목마다 카드 한 장 — 이번 주 한 줄 요약 | 공시 판독(호재/악재·강도) |
| **③ 기업 노트** | 카드를 누르면 한 장짜리 글: 요즘 주가 · 회사 사정(재무를 쉬운 말로) · 공시가 무슨 뜻인지 · 좋게 본 것과 걱정되는 것 · 외국인·기관 매매 · 작은 차트 · 원문 링크 | 기업 노트 탭(`report._note*`) · 사업보고서 변화 · 리스크 태그 · 출처 체인 |
| **④ 캘린더** | 내 종목·관심 종목의 실적 발표·배당·주총·주목할 일정 | 공시 기반 일정(`event_schedules`) |

**기업 노트의 원칙** (지금 기업 노트 탭과 같다)
- 하고 싶은 말이 앞 문장, 숫자는 괄호로 빼고 흐리게.
- 질문형 소제목 — 「요즘 주가는 어땠나요」「회사 사정은 어떤가요」.
- 어려운 용어는 처음 나올 때 한 줄로 풀어준다.
- **모든 문장에 원문 링크.** 숫자는 코드가 계산하고 LLM은 옮겨 적기만 한다 — 「쉬운데 틀리지 않는 글」이 차별점이다.
- 공개판에서는 **「그래서 비중은 이렇게 정했어요」 절과 20일 예측을 뺀다.**

---

## 5. 우리만 할 수 있는 기능 — 뉴스와 내 종목을 잇기

> 「환율이 크게 올랐어요. 지난 몇 년을 보면 내 종목 중 **A는 환율이 오를 때 같이 오르는 편**이었고, **B는 반대**였어요.」

- 엔진이 이미 재는 **종목별 환율·금리·유가·해외지수 민감도**(`signal.macro_betas`)를 쓴다.
- 예측이 아니라 **과거에 실제로 그랬다는 측정 사실**이다 — 규제 부담이 작다.
- 네이버·토스는 이걸 보여주지 않는다. ①뉴스와 ②내 종목을 잇는 다리라 앱의 중심이 될 수 있다.
- 표시할 때 「과거 경향이고 앞으로도 그렇다는 보장은 없다」를 함께 적는다.

## 6. 네이버·토스와 비교

| | 네이버페이 증권 | 토스증권 | 한장 |
|---|---|---|---|
| 성격 | 정보 포털 | 증권사 (매매 본업) | 해설 노트 |
| AI | AI 브리핑 — 시황 1시간 간격 요약 | AI 시그널 — 내 종목이 왜 움직였나 · AI 어닝콜 · 실시간 이슈 20 | 종목별 한 장짜리 해설 + 뉴스↔내 종목 민감도 |
| 질문 | 시장에 무슨 일? | 오늘 왜 올랐나/내렸나? | **이 회사 지금 괜찮은가?** |
| 재무·공시 | 표로 제공 | 거의 없음 | 쉬운 글의 중심 |
| 범위·속도 | 6개국·ETF·코인, 실시간 | 국내·해외, 실시간 | 국내 약 200종목, 하루 한 번 |
| 커뮤니티·매매 | 토론방 / 연계 | 커뮤니티 400만 / 매매 | 없음 |

**정보량·속도·차트로는 이길 수 없다.** 차트와 수급 표는 핵심만 작게 넣고, 글에 힘을 준다.
가장 큰 위험: **토스가 AI 시그널을 「쉬운 해설」로 넓히는 것.** 지킬 것은 기술이 아니라 말투·정확성·꾸준함으로 쌓이는 신뢰다.

## 7. 만들 수 있나 — 지금 있는 것과 새로 만들 것

| 필요한 것 | 상태 |
|---|---|
| 기업 노트 (쉬운 말투·좋게 본 것·걱정되는 것) | ✅ 있음 — 기업 노트 탭 |
| 공시 판독 · 사업보고서 변화 · 리스크 태그 | ✅ 있음 |
| 재무 · 거시 민감도 | ✅ 있음 |
| 외국인·기관 매매 | ⚠️ 있음 — 하지만 토스 출처라 **개인용만** (§8) |
| 일정 | ⚠️ 일부 — 공시 기반만. 배당·주총은 보강 필요 |
| 모바일 화면 | ✅ 지금 리포트가 모바일 탭 화면 |
| 종목 입력 · 회원 · 서버 · 배포 | ❌ 새로 — 이 프로젝트 |

**퀀트점프와 잇는 방법** — 한 방향, 파일로만.

```
퀀트점프 ──(공개해도 되는 것만 종목별 노트 JSON 으로 내보냄)──▶ 한장
```

- 퀀트점프가 매일 종목별 노트 JSON 을 만든다. **비중·예측·토스 수급은 처음부터 빼고** 만든다.
- 한장은 그 파일만 읽는다. 퀀트점프 DB 에 손대지 않는다. 퀀트점프는 한장의 존재를 몰라도 된다.
- 내보내기를 붙이는 순간 퀀트점프 불변식 16 을 처음 건드린다 → **퀀트점프 쪽에 ADR 먼저.**
- 데이터 계약을 맺으면 공개용 데이터는 한장이 직접 받아오는 쪽으로 옮긴다.

**노트는 종목마다 한 번만 만든다.** 200종목 노트를 만들어 두면 사용자가 1명이든 1만 명이든 각자 자기 종목만 골라 보여준다 — 사용자가 늘어도 LLM 비용은 거의 늘지 않는다.

## 8. 걸림돌 — 확인 전 가정

| 항목 | 내용 | 확인할 곳 |
|---|---|---|
| **데이터 사용권** (가장 큼) | 토스 수급은 개인용. 네이버는 화면 구성만 참고, 데이터는 못 가져온다. 차트용 시세·외국인/기관 매매를 서비스에 쓰려면 거래소·데이터 회사(코스콤·에프앤가이드 등)와 유료 계약일 가능성이 크다. **무료로 쓸 수 있는 것**: DART 공시·재무, 공공데이터포털 시세(하루 늦은 종가 — 상업 이용 조건 확인). 뉴스는 제목·링크·우리 요약까지 (퀀트점프 ADR-077) | 각 소스 이용약관 · 퀀트점프 `docs/data-sources.md` |
| **규제** | 무료·사실 위주면 위험이 낮다. **유료 구독**으로 개별 종목의 좋은 점·나쁜 점을 내면 유사투자자문 경계 | 금융 전문 변호사 · 금감원 |
| **계좌 연결** | 자동 연결(마이데이터)은 별도 라이선스 — 학생 팀은 어렵다. 처음엔 **직접 입력**. 나중에 사용자 본인의 증권사 API 키(토스 오픈API · KIS) | — |
| **경쟁** | 토스·네이버가 비슷한 기능을 붙일 수 있다 | 시험 결과로 판단 |
| **도움이 되나** | 이해에는 도움. **수익률이 좋아진다고는 말하지 않는다** — 「왜 떨어졌는지 몰라 겁먹고 파는 일」을 줄이는 정도 | 시험 사용자 인터뷰 |

## 9. 진행 순서

| 단계 | 할 일 | 넘어가는 조건 |
|---|---|---|
| **0. 샘플** | 지금 기업 노트 하나를 공개판으로 — 비중·예측 빼고, 용어 풀이와 거시 민감도 문장 넣기 | 내가 읽어서 「남에게 보여줄 만하다」 |
| **1. 모바일 웹** | 앱이 아니라 웹. 화면 ②③④만 · 종목 직접 입력 · 차트는 하루 늦은 종가로 단순하게 | 동작 |
| **2. 20명 6주 시험** | 주식 하는 지인·커뮤니티 20명. 매주 자기 종목 노트 | **계속**: 6주째에도 절반 넘게 다시 열어보고, 5명 이상 「돈 내고도 보겠다」 · **접음**: 3주째 재방문 30% 미만 — 시작 전에 정해두고 바꾸지 않는다 |
| **3. 넓히기** | ①경제 뉴스 + 민감도 연결 · 데이터 계약 · 법률 확인 | 계약·확인 완료 |
| **4. 정식 앱 · 제휴** | 앱 출시 · 사용자 숫자를 들고 증권사 제휴·공급 협상 | 사용자 수 |

**성패는 기능 개수가 아니라 「이 노트를 매주 다시 열어보는가」에서 갈린다.** 그걸 가장 싸게 확인하는 것부터 한다.
