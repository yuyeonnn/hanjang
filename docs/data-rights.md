# 데이터 사용권 확인 (0.5단계)

> 2026-10-07 각 출처의 이용약관 **원문**을 읽고 정리했다. 법률 자문이 아니다 — 유료화 전에는 전문가 확인 ([PRD.md](PRD.md) §9).
> 약관은 바뀐다. 실제로 쓰기 직전에 한 번 더 본다.

## 한 장 요약

| 재료 | 출처 | 서비스에 쓸 수 있나 | 할 일 |
|---|---|---|---|
| 공시 · 재무 · 사업보고서 · 일정 | OpenDART | ✅ **쓸 수 있다** | **기업용** 인증키로 신청 |
| 환율 · 국고채 금리 | 한국은행 ECOS | ✅ **쓸 수 있다** (출처 표시) | 지표마다 「작성기관」 확인 |
| 미국 10년 금리 | FRED | ⚠️ **쓰지 않는다** | 대신 ECOS 의 해외 금리 |
| **주가 (시세)** | 공공데이터포털 | ❌ **안 된다** — 상업적 이용 금지 · 제3자 제공 금지 | 한국거래소 유료 데이터 **견적 문의** |
| 주가 (시세) | KRX OPEN API | ❌ **안 된다** — 비상업 · 제3자 제공 금지 | 〃 |
| 뉴스 | 구글 뉴스 RSS | ❌ 비상업 용도 | 1단계는 뉴스 데이터 없이 |
| 뉴스 | 네이버 검색 API | ❌ 가공·AI 요약 금지 + 한장 불변식 3 | — |
| 뉴스 | 빅카인즈 (언론진흥재단) | ❓ 조건 공개 안 됨 | 문의 |

**가장 큰 결론: 주가는 무료로 쓸 수 있는 길이 없다.** 시세의 원래 주인은 한국거래소이고, 공짜로 열린 창구(공공데이터포털·KRX OPEN API)는 모두 「상업 금지 · 남에게 제공 금지」다.
무료 20명 시험도 「제3자 제공」에 해당해서 피해 갈 수 없다.

---

## 1. OpenDART (금융감독원) — ✅

- 약관에 **상업적 이용을 막는 조항이 없다.** 신청할 때 「개인용 / 기업용」을 고르고, 기업용은 회사명·사업자번호를 낸다 (제7조).
- 「서비스는 원칙적으로 무료」(제11조). 호출 횟수에 한도가 있다(홈페이지 게시, 제10조).
- 약관에 없는 저작권 문제는 「저작권법 및 공공데이터법에 따른다」(제16조 ④). 공시는 법에 따라 공개되는 정보다.
- 출처: [OpenDART 이용약관](https://opendart.fss.or.kr/intro/terms.do)

**할 일**: 서비스용은 **기업용 키**로 따로 받는다(사업자 등록이 필요할 수 있다 — 시험 단계는 개인용으로 시작하고 사업자를 내면 바꾼다).

## 2. 한국은행 ECOS — ✅

- 제5조 ①: **「이용자는 통계정보를 상업적으로 이용할 수 있습니다.」** 단, 작성기관이 상업 이용을 제한한 통계는 그 기관의 승인이 필요하다.
- 제7조 ②: **「ECOS에서 제공된 정보임을 표시하여야 합니다.」** → 노트와 「계산 방법」 페이지에 「자료: 한국은행 ECOS」.
- 출처: [한국은행 경제통계 Open API 이용약관](https://ecos.bok.or.kr/api/#/AuthKeyApply) (약관 보기)

**할 일**: 쓸 지표(원/달러 환율 · 국고채 3년)마다 ECOS 의 「작성기관」을 확인한다 — 한국은행이 아니라 다른 기관(예: 금융투자협회)이 작성한 통계면 그 기관 조건을 본다.

## 3. FRED (미국 세인트루이스 연준) — ⚠️ 쓰지 않는다

- 미국 10년 금리(`DGS10`) 자체는 「Public Domain: Citation Requested」 — 출처만 밝히면 되는 자료다. ([DGS10](https://fred.stlouisfed.org/series/DGS10))
- 하지만 FRED 약관은 상업 이용을 「내부 업무 · 교과서 · 뉴스레터 · 고객 보고서」로 한정하고, **「FRED 콘텐츠를 … 생성형 AI 등과 연관해 사용하지 말라」**는 조항이 있다. ([FRED 약관](https://fred.stlouisfed.org/legal/terms/))
- 한장은 AI 가 노트를 쓴다 — 이 조항에 걸릴 수 있다.

**할 일**: 미국 금리가 필요하면 **ECOS 의 해외 금리 통계**로 대신한다. 1단계는 국내 지표(환율·국고채)만으로 시작해도 된다.

## 4. 주가 — ❌ 무료 길 없음

| 창구 | 약관 원문 |
|---|---|
| [공공데이터포털 · 금융위원회_주식시세정보](https://www.data.go.kr/data/15094808/openapi.do) | 이용허락범위 **「출처표시, 상업적 이용금지, 변경금지 (제4유형)」** · 「상업적 목적 여부와 상관 없이 **제3자 무단 제공 및 재배포가 엄격히 금지**됩니다. 상업적 목적으로 이용할 경우 … 한국거래소의 KRX Data Marketplace 에서 **유료로 구매**하여야 합니다.」 |
| [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp) | 「API 서비스를 **비상업적인 목적으로만** 이용할 수 있으며」 · 「한국거래소로부터 제공받은 정보를 **제3자에게 제공할 수 없다**.」 |

**뜻하는 것**: 가격 절(「요즘 주가는 어땠나요?」) · 1년 차트 · 거시 민감도(주가 수익률로 잰다)는 **유료 데이터를 사기 전까지 쓸 수 없다.** 수익률이나 β 처럼 가공한 숫자도 원래 시세에서 나온 것이라 같은 조건을 받는다고 보는 게 안전하다.

**할 일**:
1. **한국거래소 KRX Data Marketplace 에 견적 문의** — 「하루 늦은 종가 · 약 100종목 · 웹 서비스 표시」 조건으로. (코스콤·에프앤가이드 같은 데이터 회사도 같은 질문으로 비교)
2. 견적이 나오기 전까지 1단계 노트는 **가격 없이**: 재무 · 공시 · 사업보고서 · 일정만으로 쓴다. 대신 「지금 주가는 증권사 앱에서 확인하세요」 한 줄.
3. 재무 숫자 중 **PER·PBR 도 주가가 필요하다** — 같은 이유로 빠진다. 부채비율·ROE·매출·영업이익 증감은 DART 만으로 된다.

## 4-1. 업종 이름 — ✅

DART 회사 개황의 업종 코드(통계청 **한국표준산업분류**)를 쓴다. 공공데이터포털의 분류표 파일은 4유형(상업 금지)이지만, 분류 자체는 **통계청 고시**라 저작권법 제7조(보호받지 못하는 저작물 — 국가의 고시)로 자유롭게 쓸 수 있다. 화면의 이름표는 그 코드를 우리가 쉬운 말로 줄인 것(`sources.INDUSTRY`)이다.

## 5. 뉴스 — ❌ 지금 쓸 수 있는 길 없음

> **결정 (2026-10-07, 사용자): 뉴스 문제는 서비스화 때로 미룬다.** 개발 중에는 퀀트점프처럼 구글 뉴스 RSS 로 자동 수집해 **나 혼자** 본다(구글 약관의 개인용 범위). **20명 시험처럼 남에게 보이기 전에는 반드시 바꾼다** — 후보: ① 사람이 읽고 사실 메모 → AI 문장(주 1시간쯤) ② 빅카인즈 스타트업 지원 ③ 통신사 소규모 계약 ④ 공시로 쓰는 「이번 주 소식」만. 참고: 토스증권은 다우존스 등 6개사와 **유료 제휴**로 번역·AI 요약 권리를 산다 ([보도자료](https://corp.tossinvest.com/en/news-room/detail?id=42091)).

### 5.1 빅카인즈·해외 뉴스 API 추가 확인 (2026-10-07)

| 창구 | 약관 원문 | 판단 |
|---|---|---|
| 빅카인즈 | 사이트 하단: 「빅카인즈에서 제공되는 모든 기사는 「저작권법」의 보호를 받으며, 이를 **전재, 복제, 배포하는 행위를 금합니다**.」 API 는 공공기관·연구·대학 사업단·**재단 스타트업 지원사업**을 통해 준다 | 열린 창구는 없다 — **지원사업 신청이나 재단과 협의**로만 |
| [NewsData.io](https://newsdata.io/terms) (해외, 유료) | 유료 이용자는 데이터를 「internal and external business purposes」로 쓸 수 있다. **그러나** 기사 원문은 「**third parties** 소유」이고 「**right to use** 에 대해 보증하지 않는다」 · 제3자 청구는 이용자가 책임진다 | 돈을 내도 **언론사 저작권은 해결되지 않는다** — 위험이 우리에게 넘어온다 |
| [Marketaux](https://www.marketaux.com/tos) (해외) | 「personal, non-commercial use」 · 「commercial endeavors except those specifically **endorsed or approved by us**」 | 상업은 별도 승인 |
| NewsAPI.org · Finnhub (해외) | 무료 플랜은 비상업·개발용. 상업은 유료 플랜 | NewsData 와 같은 문제(언론사 권리) |

**번역은 오히려 더 나쁘다.** 남의 기사 제목·요약을 번역하면 「2차적 저작물」이 되어 원 저작자 허락이 더 필요해진다. 해외 매체도 한국 중소형주는 거의 다루지 않는다(삼성전자·SK하이닉스 정도).

**확실한 길은 「언론사와 직접 계약」뿐이다.** 포털·증권사 앱이 그렇게 한다 (예: 포털이 연합뉴스에 연 100억 원대를 지급해 왔다 — [기자협회보](https://www.journalist.or.kr/m/m_article.html?no=50467)). 작은 규모 계약 조건은 문의해야 안다.

**할 일**:
1. 1단계 노트는 **뉴스 데이터 없이**. 대신 「이 회사 최근 뉴스 보기 →」 **검색 링크 하나**만 둔다 (데이터를 가져오지 않는 링크는 문제없다).
2. 빅카인즈(언론진흥재단)에 **스타트업 지원사업** 또는 이용 협의를 문의한다.
3. 통신사(연합뉴스·뉴스1·뉴시스) 중 한 곳에 **작은 규모 콘텐츠 계약** 조건을 문의한다.
