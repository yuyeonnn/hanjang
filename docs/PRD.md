## 1. 목표와 성공 기준

**목표: 「이 노트를 매주 다시 열어보는가」를 가장 싸게 확인한다.**

성공·실패 기준은 시험 **시작 전에** 아래로 못박고 바꾸지 않는다 ([concept.md](concept.md) §9).

| | 기준 | 재는 법 |
|---|---|---|
| **계속** | 6주째에 시험 사용자 **절반 넘게(11명+)** 그 주에 노트를 1번 이상 열었다 **그리고** **5명 이상** 「돈 내고도 보겠다」 | `note_views` 주별 고유 사용자 수 · 6주째 설문 |
| **접음** | 3주째 재방문 **30% 미만(6명 미만)** | `note_views` |
| 그 사이 | 계속도 접음도 아니면 — 6주 끝에 데이터를 보고 한 번만 정한다. 기준을 고치지 않는다 | |

「다시 열었다」 = 그 주(월~일)에 자기 종목 노트 페이지를 1번 이상 연 것.

## 4. 노트 규칙 (F4 상세)

1. **숫자는 퀀트점프가 계산해 JSON 으로 내보낸 값만 쓴다.** 한장은 계산하지 않는다 — 퍼센트 표시·반올림만.
2. **문장도 내보낸 JSON 에 있는 것만.** 1단계에서는 한장 쪽 LLM 호출이 없다 — 퀀트점프 writer 가 쓴 문장을 그대로 싣는다. (한장에서 LLM 을 쓰게 되면 그때 「옮겨 적기만, 숫자 대조 검사」 규칙을 이 절에 추가한다.)
3. **모든 문장에 링크.** DART 접수번호 → DART 원문. 계산값(가격·민감도·밸류) → 「계산 방법」 공개 페이지의 해당 항목.
4. **용어 풀이는 한장이 가진 고정 사전**(용어 → 한 줄)에서 붙인다. 노트에서 처음 나올 때만.
5. 민감도 문장 뒤에는 항상 「과거에 그랬다는 측정이지, 앞으로도 그렇다는 보장은 없어요.」
6. 노트 맨 아래 고정 문구: 「사라·팔아라는 의견도, 목표주가도, 앞으로의 예측도 없어요.」
7. **금지어 검사**: 내보낸 JSON 을 받을 때 `매수·매도·비중·목표주가·예측·전망·오를 것·내릴 것` 이 있으면 그 종목 노트를 싣지 않고 로그만 남긴다.
8. **뉴스는 짧은 글 + 기사 목록.** 글은 기사를 하나씩 나열하지 않는다 — **이번 주 이야기 하나로 묶고, 노트의 다른 숫자(작년 실적·민감도·일정)와 이어서** 「그래서 이 회사에 무슨 뜻인가」까지 간다. 글은 **기사 제목만** 보고 쓴다(본문은 가져오지 않는다 — 불변식 3). 기사에 나온 기대·전망은 「기사 제목들은 ~라고 써요」처럼 **그 기사의 말로** 옮기고, 끝에 「한장의 예측이 아니에요」를 붙인다. 문장마다 해당 기사 링크. **누가 쓰나는 미정** — 퀀트점프 [ADR-096](../../quant-jump/docs/decisions.md) 결정 5 로 첫 내보내기엔 새 LLM 글이 없다. 이어 쓴 글(뉴스·절 전체)을 어디서 쓸지(퀀트점프 writer 부기 vs 한장 쪽 writer + 숫자 대조 검사)는 1단계 시작 전에 정한다. 그 전까지는 제목 목록만.

### 5.1 퀀트점프 → 한장 노트 JSON 계약 (초안)

경계는 퀀트점프 **ADR-096** 이 정본이다 — 허용 목록 · 계산값 링크는 `ref: "calc:price|beta|value"` (한장이 「계산 방법」 페이지로 잇는다) · 재료마다 `src`(사용권 판단은 한장). 파일 `data/export/public-notes-YYYY-MM-DD.json`, 하루치 전 종목. 아래 모양은 그 초안.

```json
{
  "as_of": "2026-10-05",
  "version": 1,
  "notes": [
    {
      "ticker": "005930",
      "name": "삼성전자",
      "headline": "작년 실적은 크게 늘었는데, 주가는 석 달 전보다 낮은 자리예요.",
      "summary": "이번 주 한 줄 (카드용)",
      "tiles": [{"label": "현재가", "value": 276000, "unit": "KRW"}],
      "sections": [
        {"title": "요즘 주가는 어땠나요?",
         "sentences": [{"text": "…", "nums": {"ret_20d": 0.102}, "ref": "calc:price", "url": null}]}
      ],
      "betas": [{"macro": "YF:^SOX", "beta": 0.6, "r2": "…", "window_days": 250, "src": "yfinance"}],
      "events": [{"date": "2026-10-28", "kind": "EARNINGS", "ref": "2026…", "url": "https://dart…"}],
      "news": [{"date": "2026-10-05", "press": "마켓인", "title": "…", "url": "…"}],
      "spark": [[ "2025-10-06", 82000 ]]
    }
  ]
}
```

**처음부터 빠진 채로 나온다**: 비중 · 20일/1주 예측 · 하락 확률 · 토스 수급 · AI 매수/매도 논거 중 전망 문장.

## 7. 기술 — 가장 단순한 것

| 영역 | 고른 것 | 이유 · 바꿀 조건 |
|---|---|---|
| 서버·화면 | 파이썬 하나(서버에서 HTML 그리기) | 퀀트점프와 같은 언어. 사용자 20명이라 프론트 프레임워크 불필요. 앱 단계(4)에서 재검토 |
| DB | SQLite 파일 하나 | 20명·200종목. 동시 쓰기가 문제되면 Postgres |
| 노트 받기 | 매일 아침 JSON 파일을 읽어 `notes` 에 넣는 스크립트 1개 | 불변식 4 — 파일로만 |
| 메일 | 매직링크·주간 안내 모두 트랜잭션 메일 서비스 1곳 | |
| 배포 | 작은 클라우드 서버 1대 | 시험용 |
